1. ЧТО ЭТО ЗА ПРОЕКТ
================================================================

Производственный веб-инструмент для табачной линии SMD Cell2
(участок Cell2 разделён на 2 блока LST 1 и LST 2).

Пользователи:
- Операторы — проходят чек-лист при смене сорта.
- Технологи — управляют стандартами (OPL), настройками,
  историей, аналитикой.

Типы переходов при смене сорта:
- Minor (35 мин) — меняется табак и/или материалы.
  Бренд может не меняться (A → A).
- Intermediate (67 мин) — смена бренда + до 3 узлов.
  Бренд A → A запрещён.
- Major (90 мин) — смена бренда + более 3 узлов.
  Бренд A → A запрещён.

Технологии: чистый HTML + CSS + JS без фреймворков.
Работает через file:// (двойной клик по index.html),
без сервера. ExcelJS подключён локально.

ВАЖНО ПРО ФОТО:
Фотографии хранятся в папке photos/ рядом с index.html.
Пока нет сервера, каждый пользователь должен иметь свою
копию папки photos/. Планируется переезд на сервер —
тогда появится API для фото.

Структура папки photos:
    photos/<line>/<Maker|Packer>/<filename>
Примеры:
    photos/SD08/Maker/max-1.jpg
    photos/SD08/Packer/screenshot-1.png

В стандарте хранится ТОЛЬКО имя файла (например max-1.jpg).
Полный путь собирается автоматически через getPhotoPath().

3. УЧАСТОК И БЛОКИ
================================================================

Участок SMD Cell2 разделён на 2 блока:
- Cell2 (LST 1) — линии: SD06, SD12, SD27, SD31
- Cell2 (LST 2) — линии: SD01, SD03, SD08, SD25

Блоки редактируемые — в Настройках → «Блоки линий».
Каждая линия может быть только в одном блоке.

Машины для линий — свой список для каждой линии.
Задаётся в Настройках → «Машины для линий».
Пример: SD01: ['SE', 'M1', 'MAX'], SD03: ['SE', 'MAX'].

ВАЖНО: В форме стандарта машина выбирается из выпадающего
списка машин линии. Есть кнопка «+» для быстрого добавления
новой машины — она сразу попадает в справочник линии.

Двусторонняя синхронизация:
- Переименование машины в Настройках → обновляет её во всех
  стандартах линии.
- Удаление машины из Настроек → предупреждает, если она
  используется в стандартах, но не удаляет их.
- Импорт Excel → автоматически добавляет машины в справочник,
  если их там ещё нет.

4. СТРУКТУРА СТАНДАРТА (OPL)
================================================================

standard = {
  id: '',                        // внутренний ID
  active: true,                  // показывать оператору или нет
  number: '',                    // порядковый №
  oplNumber: '',                 // OPL № (обязательное)
  machine: '',                   // из списка машин линии
  title: '',                     // название
  line: '',                      // одна линия (SD01...)
  node: '',                      // узел
  nodePart: '',                  // Maker / Packer
  controlType: '',               // ok_not_ok / value_input / tolerance
  problemDescription: '',        // описание проблемы
  controlDescription: '',        // описание контроля
  purpose: '',                   // цель
  whyCreated: '',                // почему создан
  measurements: [                // точки замера 1–4
    { point: 1, value: '', sorts: '' },
    { point: 2, value: '', sorts: '' },
    { point: 3, value: '', sorts: '' },
    { point: 4, value: '', sorts: '' }
  ],
  appliesTo: [],                 // Minor / Intermediate / Major
  triggers: [],                  // материалы / узлы (node:Название)
  photos: [],                    // имена файлов (например max-1.jpg)
  author: '',                    // кто создал
  createdAt: null,               // дата создания (ISO)
  updatedAt: null                // дата последнего изменения (ISO)
}

11. ВКЛАДКА ДАШБОРД (tab-dashboard) — НОВОЕ
================================================================

Порядок в sidebar: между История и Настройки.
Рендерится через renderDashboard() при переключении вкладки.

Состав (все виджеты на CSS + SVG, без библиотек):

1) Верхний ряд — 5 карточек-счётчиков:
   - Стандарты — активные / всего.
   - Проверок сегодня — за текущие сутки.
   - Отклонений — сумма всех «Не ОК» за 7 дней.
   - Фотографий — всего фото / в N стандартах.
   - Заполнение фото — % стандартов с фото.

2) Средний ряд (2 колонки):
   - Слева: «Последние 5 проверок» — таблица с кнопкой
     «Открыть» (открывает модалку просмотра записи).
   - Справа: «Топ-5 проблемных стандартов (30 дней)» —
     OPL №, название, число отклонений, bar-chart.

3) Нижний ряд (2 колонки):
   - Слева: «Проверки по линиям (7 дней)» — горизонтальные
     бары с числами.
   - Справа: «Топ-5 операторов (7 дней)» — горизонтальные
     бары с числами.

4) Третий ряд (2 колонки):
   - Слева: «Проверки по дням (14 дней)» — CSS bar-chart.
   - Справа: «Типы переходов (30 дней)» — круговая
     диаграмма (conic-gradient) с легендой.

5) Быстрые действия:
   - «Начать проверку» → switchTab('check').
   - «Открыть редактор» → switchTab('editor').
   - «Проверить фото» → switchTab('settings') + открытие
     модалки проверки фото (с задержкой 200ms).

Все данные считаются из localStorage на лету.

13. РОУТЕР (js/router.js)
================================================================

- switchTab(tabName, pushHistory) — переключает вкладки
  и меняет URL (hash).
- initRouter() — навешивает обработчики + восстанавливает
  вкладку из URL при загрузке.
- URL: index.html#check | #editor | #history | #dashboard | #settings
- Восстанавливает: cl_active_tab, cl_editor_block, cl_editor_line
- Anti-flash: атрибуты data-initial-tab и data-app-ready
  на <html>.

При переключении на editor:
  if (savedLine && savedBlock) → openEditorLine(savedLine)
  else if (savedBlock) → openEditorBlock(savedBlock)
  else → renderEditorBlocksView()

При переключении на dashboard:
  renderDashboard()

Sidebar:
- Клики по <a> предотвращаются (preventDefault) и переключают
  вкладку через switchTab.
- Ссылки работают как обычные <a> для клика колесом и
  контекстного меню.

14. ФОТОГРАФИИ В СТАНДАРТАХ

- Разделители: запятая ИЛИ перенос строки.
- Поддерживается вставка из Excel (список с новой строки).
- Через Excel-шаблон — колонка «Фото» (последняя),
  значения через запятую: max-1.jpg, drum.jpg

Просмотр у оператора:
- Иконка «глаз» (.view-btn, фиолетовая) в чек-листе.
- Клик → модалка standardViewModal.
- Модалка: карточка стандарта (все поля) + галерея фото
  в правой колонке.
- Лайтбокс (lightboxModal) — просмотр фото на весь экран:
  * Пролистывание: стрелки ‹ ›, клавиши ← →, Escape.
  * Счётчик 1 / N.
  * Клик по фону — закрытие.

Модалка просмотра показывает (все поля, кроме appliesTo,
triggers, active, id, number):
- Левая колонка: название, чипы (цех, участок, линия,
  часть, машина), OPL №, описание проблемы, описание контроля,
  цель, почему создан, точки замера, тип контроля.
- Правая колонка: фотографии (сетка миниатюр),
  связанные объекты, история (автор/даты).

Проверка битых ссылок — через кнопку в Настройках.
