Бэкап данных

Скачайте бэкап — файл JSON со всеми стандартами, историей, узлами и настройками. Сохраните его в надёжном месте. При необходимости — загрузите обратно.

Блоки линий

Разделите участок на блоки. Каждая линия может быть только в одном блоке. Новый блок добавляется кнопкой «＋ Добавить блок» внутри нужного участка.

Машины для линий

Для каждой линии задайте свой список машин. Используется при создании стандартов и в фильтрах.

Триггеры Change Over

Собственные причины смены сорта, которые показываются в блоке «Что меняется». Назначаются стандартам (механическим и электронным) в качестве триггера.

Категории Top Losses

Потери, дефекты и выбросы, по которым контролируются стандарты. Оператор на вкладке «TOP Losses» выбирает конкретные потери — и получает список стандартов для проверки.

Общий список брендов

Бренды для каждой линии

Нажмите «Настроить» на нужной линии, чтобы выбрать бренды. Если у линии нет ни одного бренда — она не появится в выборе оператора.

Операторы

График смен CL Electronic

Определяет автоматический расчёт смены по дате для вкладки «CL Electronic». Порядок смен и количество дней на смену фиксированы, дата старта задаётся один раз.

Хранилище фотографий

Все фотографии стандартов лежат в папке рядом с приложением. Файлы добавляются вручную — через проводник.

Путь к папке с фотографиями:
photos/<Линия>/<Maker или Packer>/
Пример: photos/SD08/Maker/max-1.jpg
