Линии производства

Блоки линий

Разделите участок на блоки. Каждая линия может быть только в одном блоке.

Машины для линий

Для каждой линии задайте свой список машин. Используется при создании стандартов и в фильтрах.

Категории Top Losses

Потери, дефекты и выбросы, по которым контролируются стандарты. Оператор на вкладке «TOP Losses» выбирает конкретные потери — и получает список стандартов для проверки.

Общий список брендов

Бренды для каждой линии

Нажмите «Настроить» на нужной линии, чтобы выбрать бренды. Если у линии нет ни одного бренда — она не появится в выборе оператора.

Операторы

Хранилище фотографий

Все фотографии стандартов лежат в папке рядом с приложением. Файлы добавляются вручную — через проводник.

Путь к папке с фотографиями:
photos/<Линия>/<Maker или Packer>/
Пример: photos/SD08/Maker/max-1.jpg
