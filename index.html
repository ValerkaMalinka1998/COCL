Структура производства

Цех → участок → блок → линия. Линия добавляется кнопкой «+» прямо в своём блоке. Нажмите на линию — справа откроется её карточка: машины, бренды, место в структуре.

Общий список брендов

Справочник брендов по цехам. Какие бренды выпускает линия — отмечается в «Структуре» на карточке линии.

Категории Top Losses

Потери, дефекты и выбросы, по которым контролируются стандарты. Оператор на вкладке «TOP Losses» выбирает конкретные потери — и получает список стандартов для проверки.

Триггеры Change Over

Причины смены сорта для блока «Что меняется». У каждого цеха свои; в SMD триггер можно ограничить частью линии. Назначаются стандартам и E-Param на их страницах.

График смен и бригад

Две смены: день 09:00–21:00 и ночь 21:00–09:00. A, B, C, D — бригады. По этому графику Чек-лист CL, Расписание CL и COCL показывают, какая бригада на смене.

Бэкап данных

Скачайте бэкап — файл JSON со всеми стандартами, историей, узлами и настройками. Сохраните его в надёжном месте. При необходимости — загрузите обратно.

Опасная зона

Полный сброс всех данных: стандарты, история, узлы, настройки. Действие необратимо. Рекомендуется сначала скачать бэкап.
