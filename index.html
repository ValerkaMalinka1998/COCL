Структура производства

Цех → участок → блок → линия. Линия добавляется кнопкой «+» прямо в своём блоке. Нажмите на линию — справа откроется её карточка: машины, бренды, место в структуре.

SD124 цифра — сколько машин на линии · SD084 жёлтый пунктир — у линии нет брендов, оператор её не увидит

Общий список брендов

Справочник брендов по цехам. Какие бренды выпускает линия — отмечается в «Структуре» на карточке линии.

Категории Top Losses

Потери, дефекты и выбросы, по которым контролируются стандарты. Оператор на вкладке «TOP Losses» выбирает конкретные потери — и получает список стандартов для проверки.

Триггеры Change Over

Причины смены сорта для блока «Что меняется». У каждого цеха свои; в SMD триггер можно ограничить частью линии. Назначаются стандартам и E-Param на их страницах.

График смен

Дневная смена 09:00–21:00 и ночная 21:00–09:00. Буквы A, B, C, D — обозначения смен. По этому графику Чек-лист CL, Расписание CL и CL при переходах показывают, какая смена сейчас работает.

Операторы

Импорт бланков OPL

Бланк стандарта из журнала (Excel, один лист — один стандарт) превращается в стандарт выбранной линии: № OPL, машина и узел, название, автор, время на проверку, инструмент, «Описание», «Описание контроля», «Цель», «Знаю почему», точки по брендам («Все бренды» — общая норма для брендов без своей строки). Тип контроля определяется по значениям. Можно выбрать сразу несколько файлов. Уже существующие OPL № на машине пропускаются.

Нужен формат .xlsx. Старые .xls пересохраните в Excel («Сохранить как» → .xlsx) или пакетно: powershell -ExecutionPolicy Bypass -File tools\xls-to-xlsx.ps1 "папка с бланками". Фото из бланков скачиваются архивом photos_<линия>.zip — распакуйте его рядом с index.html. «CL относится к», триггеры и Top Losses задайте потом на странице стандарта.

Хранилище фотографий

Все фотографии стандартов лежат в папке рядом с приложением. Файлы добавляются вручную — через проводник.

Путь к папке с фотографиями:
photos/<Линия>/<Maker или Packer>/
Пример: photos/SD08/Maker/max-1.jpg

Бэкап данных

Скачать бэкап — файл JSON со всеми данными: стандарты, история, расписание, настройки. Бэкап с фото (ZIP) — те же данные и все фото: выберите папку photos рядом с index.html. Загрузить можно и JSON, и ZIP.

Опасная зона

Полный сброс всех данных: стандарты, история, узлы, настройки. Действие необратимо. Рекомендуется сначала скачать бэкап.

Шаблон заполняет просматриваемую неделю. Дальше, как при ручной правке, выберите «С этой недели и далее» или «Только эта неделя» и нажмите «Сохранить».

Сначала ознакомьтесь со стандартами

Проверять можно только после ознакомления с актуальной редакцией. Откройте стандарт, прочитайте и подтвердите.

Копировать стандарт

На какую линию скопировать? Только линии этого же цеха. Копия откроется для правки и появится на линии после «Сохранить».
